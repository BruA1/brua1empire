FL Studio Keyboard Shortcuts

A quick desktop reference for essential FL Studio navigation, saving and playback commands.

Search shortcuts

8 shortcuts

KeyActionUse
F5PlaylistArrange patterns and audio
F6Channel RackBuild and manage patterns
F7Piano RollEdit notes
F9MixerSet levels and effects
Ctrl/Cmd + SSaveSave your project
Ctrl/Cmd + Shift + SSave AsCreate a separate project version
SpacePlay / stopControl playback
Ctrl/Cmd + TTyping keyboard to pianoToggle musical typing mode

Single-key commands can be intercepted when typing keyboard to piano is enabled. Function keys may require Fn on some laptops. Shortcuts can depend on focus, operating system and version.

Reference: Image-Line official shortcuts manual.

Practice a faster workflow

  1. Open Channel Rack and choose a sound.
  2. Switch to Piano Roll to write a melody.
  3. Open Playlist and arrange your pattern.
  4. Open Mixer, check the levels, then save a separate version.
