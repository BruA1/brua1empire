FL Studio Beginner's Guide

Make your first eight-bar beat by learning the Channel Rack, Piano Roll, Playlist and Mixer.

Start learningDiscuss with producers →

Build your first beat

  1. Start a blank project. Set a tempo such as 90 BPM for a relaxed beat or 120 BPM for a faster groove. Save a named project before you begin.
  2. Build drums. Add a kick, snare and hi-hat from sounds you have rights to use. Place kicks and snares in a simple four-beat pattern, then add hats. Listen before adding more sounds.
  3. Write a melody. Open the Piano Roll on an instrument, choose a small group of notes and write a two-bar phrase. Leave some space for the drums.
  4. Arrange. Place patterns in the Playlist, repeat them to eight bars and make a small variation at the end. Compare the first and second halves.
  5. Mix. Assign instruments to Mixer inserts. Adjust levels while listening to the whole beat. The Playlist track number alone does not determine Mixer routing.
  6. Export. Save a separate project version and export a WAV or MP3 demo using the export menu. Listen to the result outside FL Studio before sharing it.

Try the exercise with just four sounds. Finish the arrangement before adding more plugins.

Add movement and improve the groove

Use automation to move a supported parameter across the arrangement. For example, automate a filter cutoff for a transition; listen to the beginning and end values and check that the change fits the rhythm.
